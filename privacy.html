Privacy Policy: "factory" upload tool

Last updated: 18 November 2026

"factory" is a private tool used only by the owner of the YouTube channels The Reels of the Past, Chalk & Gears and The Coin Atlas to upload and schedule their own videos and read their own channel statistics. It is not offered to the public.

What the tool accesses
With the owner's sign-in, the tool uses the YouTube Data API and YouTube Analytics API to upload videos, set titles, descriptions, thumbnails, captions, playlists and publish times, and to read view and audience statistics for these channels only. It also uses the Instagram API to publish Reels to the matching Instagram accounts and read their insights.

What is stored
Sign-in tokens and statistics are stored only on the owner's own computer. Nothing is sold, shared with third parties, or used for advertising. No data from other YouTube users is collected.

Google API Services
The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Use of Instagram data follows the Meta Platform Terms.

Removing access
Access can be revoked at any time at https://myaccount.google.com/permissions. Deleting the token files on the owner's computer removes all stored data.

Contact
Questions: via the "About" page of any of the three channels on YouTube.
